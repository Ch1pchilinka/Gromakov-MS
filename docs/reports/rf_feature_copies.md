Проводим эксперимент по проверке сохранения силы взаимодействия в моделях RF, RF + RIT, RF + TreeSHAP.
Проверяем на датасете Airfoil, 1503 измерения, 5 признаков. В Airfoil сначала фиксируем Частоту и добавляем
копии Толщины вытеснения, затем наоборот. Добавляем $k = 0, 1, 2, 4, 8$ копий.

Подбор гиперпараметров идет следующим образом. Сначала выбирается rit_alpha, затем по CV подбираются остальные
гиперпараметры. Обычный RF = RIT с rit_alpha = 0. Для RIT сравниваем получившееся качество с качеством на RF.
Вместо условия RMSE(RIT) <= RMSE(RF)для того, чтобы rit_alpha был не почти 0 (0.02 где-то получалось с этим
условием либо вообще не подбирался), иначе не было бы нужного эффекта, я сделал подбор rit_alpha до значимого
ухудшения качества либо до падения на 5%.
